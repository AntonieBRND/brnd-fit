# BRND FIT

Fitness-app voor Antonie en Mels: trainingen loggen en inplannen (fitness en padel), voortgang en records, samen trainen,
slaap & herstel en Apple Gezondheid (stappen, slaap, kcal) via een iPhone-automatisering.

- Live: https://antoniebrnd.github.io/brnd-fit/
- Installatie en Supabase: zie [SETUP.md](SETUP.md)
- Bron: `src/app.html` → `node tools/build.mjs` maakt `index.html`.
- 3D-anatomie: Z-Anatomy (CC BY-SA 4.0), gebaseerd op BodyParts3D © DBCLS (`body/`).
